## 2026年11月23日 — ESP32の動作確認とIC2通信

### 1. 目的
ESP32の初期不良がないかの確認。初期設定を完了して、ADXL345加速度センサーとのI2C通信を確認

### 2. 実施内容
・ADXL345にピンヘッダーのはんだづけ
・CP2102ドライバーの設定
・Arduino IDEのボードおよびポート設定
・LED点滅プログラムによる動作確認
・ESP32とADXL345の配線
・I2C通信確認プログラムの作成
・シリアルモニターによる実験結果の確認

### 3. 発生した問題
# 問題１：PCとのESP32の接触不良
接続を行ってもパソコンやArduino IDEに認識されなかった。
# 問題２：プログラムの書き込みエラー
コンパイルには成功したが、書き込み時にエラー発生
### 4. 原因と解決方法
デバイスマネージャーを使用して認識情報を確認してドライバーの設定を行った。書き込みに必要について調べた。
### 5. 実験結果
LEDが一定間隔で点滅することを確認。
ADXL345との通信確認では、以下の項目を確認

SDA         GPIO21
SCL         GPIO22
I2Cアドレス　0x53
シリアル通信速度　115200 baud
通信確認感覚　1000ms

シリアルモニターに以下の結果が繰り返し表示された
error code: 0
ADXL345 connected!
### 6. 学んだこと・考察
マイコンとPCを接続する際のドライバーの役割
コンパイルとアップロードの違い
ESP32のBOOTモードの役割
I2C通信におけるSDAとSCLの役割
シリアル通信と通信速度の意味
関数の戻り値を使用した通信結果の判定方法
今回の実験では通信の成立を確認できたが、実際の加速度データの取得できていない
### 7. 次回の目標
ADXL345から3軸の加速度データを取得
センサーを静止させた場合と動かした場合の数値を比較
加速度データから振動を検出する方法を検討
